# ballot-package-candidate-election

A public, non-binding approval election selecting Council candidates by stable machine identifiers.

Decision type: `candidate-election`.

Object family: `ballot-package-v1`.

The package contains the explicit forgeable proof marker `TEST_ONLY_NOT_ANONYMOUS_NOT_FOR_BINDING_ELECTIONS` and is not anonymous or suitable for binding elections.

The canonical CBOR bytes are authoritative. JSON and hexadecimal files are presentation artifacts.
